From a new light and dark mode switcher to ZIP support, automatic software updates, and a redesigned Designify editor, there's quite a bit to explore in this release.

## What's New

### Light & Dark Mode

Reviactyl now includes a light/dark mode switcher, giving you more control over how the panel looks and feels. Whether you prefer a darker interface or a brighter one, you can switch between the two to suit your preference.

### ZIP Support for Files & Backups

File management just got more flexible with ZIP support. You can now use ZIP compression for files and backups, making it easier to package and manage your server data.

### Automatic Software Updater

Keeping your panel up to date is now more convenient with the new in-panel automatic software updater. Instead of relying entirely on manual update workflows, you can manage software updates for panel and agent directly from within the panel.

### Better File Moving Experience

Moving files now comes with an improved interface that's designed to make the process more straightforward. This update also improves the overall user experience when navigating file operations.

### Backup Aliases & Renaming

Backups can now have aliases, making it easier to identify them without relying solely on their original names. This is especially useful when managing multiple backups and trying to keep everything organized.

### A New Designify Editor

The Designify editor has received a redesign, bringing a refreshed editing experience to Reviactyl's customization tools.

## Improvements & Fixes

Alongside the new features, we've made several improvements across the panel to make things more consistent, reliable, and easier to use.

* **Tailwind CSS v4 migration:** Updated the frontend styling stack to Tailwind CSS v4.
* **TypeScript 6 upgrade:** Brought the project forward with an upgrade to TypeScript 6.
* **Bulk server deletion:** Fixed issues affecting bulk server deletion.
* **Node FQDN validation:** Improved validation for node fully qualified domain names.
* **Console tab visibility:** The console tab now remains visible in compact and accent layouts.
* **User location metrics:** Replaced the user location metrics visualization with a bar chart for a clearer presentation of the data.
* **Node configuration updates:** Changes made to nodes are now propagated to the agent.
* **Improved server search:** Made server searching more useful and convenient.
* **File move UX:** Further refined the file-moving experience alongside the new interface.
* **Security fix:** Addressed [GHSA-737j-g749-rhrp](https://github.com/reviactyl/panel/security/advisories/GHSA-737j-g749-rhrp).
* **Consistent alerts:** Standardized alert box styling across the panel for a more consistent interface.
